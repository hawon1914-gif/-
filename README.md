# Aero Lab

심레이싱 관점에서 공기역학, 하중 이동, 슬립스트림을 실험하는 프로그램입니다.
F1(2021·2022 규정), LMH/LMDh 하이퍼카, Valkyrie급·Chiron급 로드 하이퍼카, GT3, 고성능 로드카를 같은 조건에서 비교합니다.

## 실행

**`AeroLab.html` 하나를 더블클릭하면 끝입니다.** 서버도, 인터넷도, 설치도 필요 없습니다. 3D 엔진, 유체 해석기, 차량 모델이 전부 이 파일 하나에 들어 있습니다. (크롬·엣지 권장)

이 파일은 저장소에 올리지 않습니다. 출처를 확인하지 않은 개인용 3D 모델(`assets/models/user/`)이 들어가기 때문입니다. 직접 만들려면:

```bash
npm install
npm run build   # dist/AeroLab.html 생성 (assets/models/user/에 있는 모델도 함께 포함)
npm test        # 물리·주행·코칭 테스트 (Node) + 브리지 테스트 (Python)
```

개발 중에는 `start.bat`(Windows) 또는 `./start.sh`(macOS·Linux)로 로컬 서버를 띄워 `index.html`을 직접 열 수 있습니다. 이 방법은 Python 3가 필요합니다.

## 실험

| 탭 | 내용 |
| --- | --- |
| 3D 풍동 | 차종별 3D 모델과 실시간 2D 격자 볼츠만 유동 해석(중앙 단면/측면 실루엣), 3D 유선, 풀 브레이킹 자세, 앞차 후류, .glb 모델 불러오기 |
| 주행 | 엔진 토크 곡선·기어·터보가 있는 시간 영역 주행. 가속·브레이크·변속을 직접 조작(키보드·화면 버튼·게임패드), 이상 랩과 AI 비교, 베스트 대비 실시간 델타 |
| 코칭 | 르망 얼티밋 주행 분석. 기준 랩은 같은 세션에서 같은 클래스로 가장 빠른 랩(누가 달렸든, 다른 기록 파일 포함). 게임 공식 랩 타임·섹터·트랙 리밋 판정 사용. 개선할 것 요약, 코너별 원인과 고칠 점, 브레이킹 구간 비교, 라인 비교, 스핀·이탈·충돌 원인 분석, 고스트 재생(페달 표시), 실시간 미니맵(항상 위 창, 실제 서킷 모양을 자동으로 맞춰 처음 가는 트랙도 바로 표시), 트랙·날씨. 연결은 `bridge/README.md` 참고 |
| 속도 스윕 | 속도별 앞/뒤 다운포스와 항력, 라이드하이트, 최대 감속·횡G, 필요 출력, 최고속도 |
| 브레이킹 | 감속 G, 하중 이동, 노즈 다이브에 따른 다운포스·에어로 밸런스 변화, 한계 축, 이상적 바이어스, 강체 에어로와 비교, 자세 리플레이 |
| 슬립스트림 | 간격별 항력 감소와 다운포스 손실(앞/뒤 따로), 더티 에어 속 코너링 G, 직선 드래그 레이스(추월 지점, DRS) |
| 차량 비교 | 전체 프리셋을 같은 조건에서 비교 |

## 모델

- **준정적 모델**: CFD가 아닙니다. 라이드하이트에 따라 바뀌는 계수 기반 에어로맵, 하중 이동, 타이어 하중 민감도 모델을 결합합니다. 심레이싱 물리엔진과 같은 방식입니다.
- **3D 풍동**: 차의 2D 단면에서 격자 볼츠만법으로 유체 방정식을 풉니다. 격자 레이놀즈수가 실제보다 수천 배 작으므로 계수는 실제 값이 아니라 상대적인 경향으로 읽어야 합니다.

프리셋 값은 모두 공개 자료를 바탕으로 한 추정치입니다. 사용한 수식과 빠진 요소는 앱의 "모델 설명" 탭에 있습니다.

## 파일

- `js/physics.js`: 물리 모델(순수 함수)
- `js/cars.js`: 차량 프리셋과 파라미터 스키마
- `js/model3d.js`: 절차적 3D 모델, glTF 정렬, 형상을 격자로 변환
- `js/lbm-gpu.js`: 격자 볼츠만 유체 해석기(GPU, WebGL2 셰이더)
- `js/lbm-worker.js`: 같은 해석기의 CPU 버전(Web Worker). GPU를 못 쓸 때 사용
- `js/solver.js`: GPU/CPU 해석기 자동 선택
- `js/tunnel.js`: three.js 장면, 유선, 측정값
- `js/drivetrain.js`: 엔진 토크 곡선, 터보 지연, 기어, 클러치 출발
- `js/track.js`: 직선·원호로 만든 가상 트랙 (자동으로 닫힘 보정)
- `js/drive.js`: 주행 시뮬레이션 (마찰원, 휠스핀, 잠김, 트랙 이탈, 이상 속도 프로파일, AI)
- `js/drive-ui.js`: 주행 탭 화면과 입력
- `js/coach.js`: 주행 분석 (랩·코너·지표·코칭 문장)
- `js/incidents.js`: 스핀·이탈·충돌 검출과 원인 분석
- `js/coach-demo.js`: 실수를 섞은 데모 세션 (분석 검증용)
- `js/coach-ui.js`: 코칭 탭 화면, 실시간 연결, 음성 안내
- `bridge/`: 르망 얼티밋 텔레메트리 브리지 (Python, 표준 라이브러리만 사용)
- `js/chart.js`, `js/carview.js`: 차트와 측면도
- `js/app.js`: UI
- `build.mjs`: 단일 HTML 빌드 스크립트(esbuild)
- `js/models.js`: 3D 모델 목록과 각 모델에 맞는 차량 프리셋
- `vendor/three/`: three.js r160(MIT 라이선스)
- `vendor/postprocessing/`, `vendor/n8ao/`: 후처리(안티에일리어싱, 앰비언트 오클루전, 블룸). 각각 Zlib, ISC 라이선스
- `assets/models/`: 공개 3D 모델(라이선스는 해당 폴더의 README 참고). 개인용 모델은 `assets/models/user/`에 두며 저장소에는 올리지 않음
