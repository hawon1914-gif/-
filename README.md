# LMU 코치

르망 얼티밋(Le Mans Ultimate) 주행을 실시간으로 받아 기록하고, 세션에서 가장 빠른 랩(같은 클래스, 누가 달렸든)과 비교해 어디서 왜 시간을 잃었는지, 스핀·이탈이 왜 났고 어떻게 회복했어야 했는지 알려주는 개인용 코칭 프로그램입니다. 이 컴퓨터(Windows)에서만 씁니다.

## 실행

```bash
npm install
npm run build   # dist/LMUCoach.html 생성 (한 파일, 서버·인터넷 불필요)
npm test        # 분석 테스트 (Node) + 브리지 테스트 (Python)
```

1. `dist/LMUCoach.html`을 `bridge` 폴더에 복사합니다 (빌드할 때마다).
2. `bridge/LMU코치_실행.bat`을 더블클릭합니다. 브리지가 최소화된 창으로 켜지고 `http://127.0.0.1:8770/`이 열립니다.
3. 게임을 켜고 달리면 자동으로 연결·기록됩니다. 기록은 `bridge/recordings/*.jsonl` (세션마다 새 파일).

게임 쪽 준비와 기록 파일 형식은 `bridge/README.md`에 있습니다.

## 기능

- 기준 랩: 같은 세션·같은 클래스에서 가장 빠른 공식 랩(다른 차 포함), 다른 기록 파일의 랩, 목표 시간
- 게임 공식 랩 타임·섹터·무효 랩 판정 사용, 섹터 기준 이론상 베스트
- 개선할 것 요약, 코너 가이드(제동 시점 빠름/늦음, 내릴 기어, 코너 속도 여유, TC·ABS 개입과 덜 밟을 정도)
- 브레이킹 구간 페달 비교, 속도·누적 시간·라인 차이 차트, 코너 라인 확대 보기(휠 확대·끌기·두 번 클릭 원래대로)
- 스핀·이탈·충돌 검출과 원인, 스핀별 회복 평가(카운터스티어·스로틀·양발 브레이크·재출발), 사고 장면(차트+지도+주변 차)
- 상대 차 기록표(+/− 초), 고스트 재생(페달 HUD), 실시간 미니맵(항상 위 창), RPM, 다음 코너 안내, 음성 안내
- 트랙 지도: 실제 서킷 모양 10개를 주행 위치에 자동으로 맞춤(처음 가는 트랙도 바로 표시), 없으면 주행 위치로 생성

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 (HTML·CSS) |
| `js/main.js` | 진입점, 브리지 자동 연결 |
| `js/coach-ui.js` | 화면 동작: 실시간 연결, 지도, 고스트, 미니맵, 사고 장면, 차트, 코너 확대 |
| `js/coach.js` | 분석: 랩 분리, 공식 기록, 코너 검출·지표, 기준 랩, 코칭 문장, 코너 가이드 |
| `js/incidents.js` | 스핀·이탈·충돌 검출, 원인, 회복 평가 |
| `js/track-maps.js` | 실제 서킷 모양 맞춤, 주행 위치로 지도 만들기 |
| `js/track-shapes.js` | 서킷 모양 데이터 (생성 파일, 출처는 파일 머리말) |
| `js/chart.js` | 선 차트 |
| `bridge/lmu_bridge.py` | 게임 공유 메모리(LMU_Data, 없으면 rF2 SMMP) → SSE 실시간 전송 + 기록 (Python 표준 라이브러리만) |
| `build.mjs` | 한 파일 빌드 (esbuild) |
| `tests/` | `coach.test.mjs`, `trackmaps.test.mjs`, `test_bridge.py`, 고정 시험 기록 `fixtures/demo-session.jsonl.gz` |
