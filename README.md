# 카페 메뉴 웹사이트 (QR 스캔용)

QR을 찍으면 열리는 모바일 한 페이지 메뉴판.
종이 메뉴판의 남색/크림 톤과 일러스트를 그대로 옮겼고,
상단 일러스트가 스크롤에 맞춰 움직인 뒤 메뉴가 나타납니다.

## 스크롤 연출

| 스크롤 위치 | 화면 |
|---|---|
| 0 ~ 4%   | 손에 들린 빈 잔 + 가게 이름 |
| 4 ~ 32%  | 위에서 음료 줄기가 내려옴 |
| 30 ~ 56% | 잔에 음료가 차오름 (표면 물결·튀는 방울) |
| 58 ~ 86% | 음료 줄기로 줌인 → 화면이 크림색으로 덮임 |
| 87 ~ 100%| 메뉴 타이틀이 페이드로 등장, 이어서 메뉴 |

`js/app.js` 가 스크롤 진행도(0~1)를 계산해서 CSS 변수로 넘기고,
`css/style.css` 와 SVG 가 그 값을 받아 움직입니다.

| 변수 | 뜻 |
|---|---|
| `--pour`  | 음료 줄기가 내려온 정도 |
| `--jet`   | 줄기가 잔에 닿았는지 |
| `--level` | 잔에 찬 정도 |
| `--splash`| 튀는 방울 |
| `--zoom`  | 줄기 확대 배율 |
| `--wash`  | 화면을 덮는 크림색 |
| `--end`   | 마지막 메뉴 타이틀 |

기기 설정이 "동작 줄이기"면 연출은 자동으로 꺼지고 메뉴가 바로 보입니다.
우측 상단 `MENU ↓` 버튼으로 연출을 건너뛸 수도 있습니다.

## 파일 구조

```
index.html          페이지 + 일러스트 SVG (손·잔·줄기)
css/style.css       스타일. 맨 위 :root 에 색/폰트 토큰
js/menu-data.js     ★ 메뉴 내용 — 보통 여기만 고치면 됨
js/app.js           스크롤 연출 + 메뉴 렌더링
qr.html             배포 주소를 넣으면 QR 이미지를 만들어 주는 페이지
```

## 수정한 게 반영이 안 될 때 (캐시)

브라우저가 이전 파일을 기억하고 있어서 그렇습니다. 두 가지로 대응합니다.

- **확인용**: 주소 뒤에 `?v=아무값` 을 붙여 엽니다 → `.../-/?v=2`
- **배포용**: CSS/JS 를 고쳤으면 `index.html` 안의 `?v=2` 숫자를 하나 올립니다.
  그래야 손님 휴대폰이 새 파일을 받아옵니다.

## 메뉴 수정

`js/menu-data.js` 만 고치면 됩니다. HTML은 건드릴 필요 없습니다.

```js
{ fr: "Americano", ko: "아메리카노", price: "4.0" }
```

- `ko` 는 생략 가능, `price` 는 적은 문자열이 그대로 출력됩니다 (`"5.5 / 6.0"` 가능)
- 카테고리에 `mark: "✱"` 를 주면 제목 옆에 표시가 붙습니다
- 맨 위 `cafe` 에 가게 이름·주소·영업시간·인스타를 넣으면 히어로와 푸터에 반영됩니다
  (빈 문자열이면 그 줄은 표시되지 않습니다)

## 톤 바꾸기

`css/style.css` 맨 위:

```css
--navy:  #1e1a4b;   /* 메뉴판 남색 */
--cream: #f2ede1;   /* 일러스트 선 */
--milk:  #e7e0cd;   /* 음료 */
--paper: #f6f4ee;   /* 메뉴 배경 */
```

연출 길이는 `--hero-scroll` (기본 `280vh`). 값을 줄이면 메뉴가 더 빨리 나옵니다.

## 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 배포 + QR

1. GitHub 저장소 → Settings → Pages → Source: 이 브랜치 / 루트
2. 발급된 주소를 `qr.html` 에 넣고 QR 생성 → 저장 → 인쇄
