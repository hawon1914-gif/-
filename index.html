준비 중
3D 엔진과 유체 해석기를 불러오는 중입니다.

공기 흐름은 차의 2D 단면에서 실제 유체 방정식(격자 볼츠만법)으로 계산합니다. 3D 유선은 그 단면 결과를 차폭 방향으로 펼쳐 보여주는 것이라 차 옆을 돌아 나가는 흐름은 없습니다. 격자 레이놀즈수가 실제보다 수천 배 작고 칸 크기가 수 cm라서, 박리·후류·지면효과의 경향은 보이지만 측정 계수를 실제 값으로 읽으면 안 됩니다. 라이드하이트는 격자에서 4칸 + 10mm당 1칸으로 과장합니다. 수 cm 칸에 실제 틈을 그대로 넣으면 틈이 1~2칸이 되어, 낮은 레이놀즈수에서 바닥이 오히려 양력을 받는 윤활막처럼 동작하기 때문입니다. 흰색은 자유류와 같은 속도, 파랑은 느린 공기, 빨강은 빠른 공기입니다.

앞차를 넣으면 뒤차의 항력 감소(슬립스트림)는 실제와 같은 방향으로 나옵니다. 하지만 2D에서는 후류 소용돌이가 옆으로 빠지지 못해 실제보다 훨씬 강하고, 다운포스는 오히려 늘어나게 나올 수 있습니다. 더티 에어로 인한 다운포스 손실은 FIA 수치에 맞춘 준정적 모델(슬립스트림 탭) 쪽을 믿으세요.

      르망 얼티밋 연결 방법
      1. rF2 Shared Memory Map Plugin의 rFactor2SharedMemoryMapPlugin64.dll을 르망 얼티밋 설치 폴더의 Plugins 폴더에 넣고, UserData\player\CustomPluginVariables.JSON에서 켭니다. 자세한 순서는 저장소의 bridge/README.md에 있습니다. SimHub나 CrewChief를 이미 쓰고 있다면 이미 설치되어 있을 수 있습니다.
      2. PC에서 bridge/start_lmu_bridge.bat을 실행합니다 (Python 3.8 이상 필요).
      3. 게임에서 트랙에 나간 뒤 이 화면에서 "실시간 연결"을 누릅니다. 주행은 bridge/recordings 폴더에 자동으로 기록되고, 나중에 "기록 파일 열기"로 다시 분석할 수 있습니다.

      패드나 휠은 이 프로그램에 연결할 필요가 없습니다. 게임이 받은 페달·조향 입력이 텔레메트리에 그대로 들어 있습니다.

      정속 주행에서 속도별로 다운포스, 항력, 차 자세, 한계 G가 어떻게 바뀌는지 봅니다. 다운포스는 속도 제곱에 비례하지만, 차체가 내려앉으며 지면효과가 바뀌기 때문에 정확한 제곱은 아닙니다.

      매 순간 타이어 한계까지 밟는 풀 브레이킹입니다. 노즈가 숙여지면 앞은 낮아지고 뒤는 들려서 다운포스 크기와 밸런스가 함께 바뀝니다. 속도가 줄면 다운포스가 빠지므로 감속 G도 같이 떨어집니다.

      앞차 후류 안에서는 항력이 줄어 직선에서 빨라지지만, 다운포스도 잃어 코너에서 불리해집니다. 프론트 윙이 더 많이 잃기 때문에 따라가는 차는 언더스티어가 납니다.

      무엇을 계산하나

      CFD처럼 공기 흐름을 직접 풀지 않습니다. 심레이싱 물리엔진과 같은 방식으로, 계수와 라이드하이트 기반 에어로맵에 하중 이동과 타이어 모델을 결합한 준정적 모델입니다.

      • 공기 밀도: ρ = p / (R·T), 건조 공기 가정.
      • 항력·다운포스: F = ½ρv²·CdA, DF = ½ρv²·ClA·g(h). 다운포스를 프론트와 리어로 나누고 각각 해당 축의 라이드하이트로 보정합니다.
      • 지면효과 g(h): 라이드하이트가 낮을수록 선형으로 증가하다가, 실속 높이 아래에서 급감합니다.
      • 유도항력: CdA 중 일부는 다운포스에 비례합니다. 그래서 실속하거나 더티 에어로 다운포스를 잃으면 항력도 조금 줄어듭니다.
      • 하중 이동: ΔFz = m·a·h_cg / L. 안티다이브/안티리프트 비율만큼은 피치로 이어지지 않습니다.
      • 차 자세: 에어로 하중과 하중 이동으로 스프링이 압축되고, 바뀐 라이드하이트가 다시 다운포스를 바꿉니다. 이 순환을 반복 계산으로 풉니다. 평형이 없으면 포포이징 위험으로 표시합니다.
      • 타이어: μ = μ0·(Fz/Fref)^(−k). 하중이 늘수록 마찰계수가 떨어지는 하중 민감도를 반영합니다.
      • 브레이킹: 바이어스로 고정된 앞/뒤 제동력 중 어느 한쪽이 먼저 접지 한계에 닿는 감속이 최대 감속입니다.
      • 슬립스트림: 간격에 따라 지수적으로 줄어드는 항력 감소와 다운포스 손실. F1 수치는 FIA 발표치(2021 규정: 10m에서 약 47%, 20m에서 약 35% 손실 / 2022 규정: 10m에서 약 18%, 20m에서 약 4% 손실)에 맞췄습니다.

      3D 풍동

      • 3D 모델은 차종별 치수(길이, 휠베이스, 트레드, 폭, 높이)로 코드에서 만든 형상입니다. 실제 팀 CAD는 공개되지 않습니다. 직접 구한 .glb 파일을 불러올 수 있습니다.
      • 유동은 격자 볼츠만법(D2Q9, 스마고린스키 난류 모델)으로 차의 중앙 단면 또는 측면 실루엣을 2D로 풉니다. 그래픽카드(WebGL2)로 계산하고, 안 되는 환경에서는 CPU로 자동 전환합니다. 프레임이 떨어지면 한 프레임당 계산 스텝 수를 자동으로 줄입니다. 노면은 공기와 같은 속도로 움직입니다. 바퀴는 고정된 벽으로 다룹니다. 회전하는 바퀴는 2D 단면에서 차 아래로 공기를 계속 밀어 넣어 계산이 발산하기 때문입니다.
      • 차 자세(라이드하이트, 피치)는 준정적 모델에서 가져옵니다. 풀 브레이킹을 고르면 노즈가 숙여진 상태로 유동을 다시 계산합니다.
      • 힘은 운동량 교환법으로 적분한 2D 계수입니다. 레이놀즈수가 실제보다 수천 배 작아 절대값은 의미가 없고, 같은 차의 자세 변화나 앞차 유무에 따른 상대 변화를 보는 용도입니다.

      빠진 것

      • 타이어 온도·압력·마모, 슬립 비율과 슬립 각에 따른 힘 곡선(Pacejka 같은 모델).
      • 댐퍼에 의한 과도 응답. 자세는 매 순간 평형 상태로 계산하므로 실제 포포이징의 진동 자체는 재현하지 않습니다.
      • 롤에 따른 에어로 변화, 요(yaw) 각, 횡풍.
      • 엔진 브레이크, ABS, 브레이크 온도. 엔진 출력은 회전수와 무관한 일정 출력으로 둡니다.
      • 차량별 실제 계수. 팀 데이터는 비공개라 프리셋은 추정치입니다. 절대값보다 변화의 방향과 상대 크기를 보는 용도입니다.
